## Formulaires "App Privacy" (Apple) / "Data safety" (Google)

À déclarer de façon cohérente avec `politique-confidentialite.html` :

| Question | Réponse |
|---|---|
| Collecte de données liées à l'identité | **Non** (aucun compte, aucune donnée identifiante) |
| Analytics | **Oui — anonymisé** : Google Analytics (GA4), IP tronquée, non lié à l'utilisateur, usage « Analytics » uniquement |
| Publicité / traceurs tiers | **Non** |
| Données stockées sur l'appareil (favoris, langue, reprise) | Local uniquement, non transmis — **non "collecté"** au sens des stores |
| Vente de données | **Non** |
| Données chiffrées en transit | **Oui** (HTTPS) |
| Suppression des données | L'utilisateur efface le stockage local / désinstalle l'app |

> Le seul poste à cocher côté Apple est généralement **« Usage Data → Product
> Interaction »** en mode *Not linked to you*, *Not used for tracking* (à cause
> de Google Analytics). Tout le reste = non collecté.
